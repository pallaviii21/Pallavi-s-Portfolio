# Portfolio — Pallavi Kumari

A modern, dark-themed personal portfolio website showcasing my full-stack web applications, AI integrations, and technical journey. Built with clean aesthetics, smooth animations, and a mobile-first responsive design.

## ✨ Features

- **Responsive Design** — Optimized for desktop, tablet, and mobile with fluid typography and adaptive layouts
- **Progressive Web App (PWA)** — Installable with offline support via Service Worker and Web App Manifest
- **Smooth Animations** — Fade-in, slide-up, and gradient transitions for an engaging experience
- **Custom Cursor** — Interactive cursor trailing effect across all pages
- **SEO Optimized** — Sitemap, robots.txt, Schema.org JSON-LD structured data, and OpenGraph meta tags
- **Dark Theme** — Consistent dark UI with radial gradient accents and glowing effects
- **Image CDN** — All images served via Cloudinary with responsive transformations

## 🛠 Tech Stack

| Layer | Technology |
|-------|-----------|
| **Frontend** | HTML5, CSS3, JavaScript (ES6+), React.js, TailwindCSS |
| **Backend & AI** | Node.js, Express.js, Flask, Groq LLM API, Supabase, MongoDB, PostgreSQL |
| **Tools & Platforms** | Docker, AWS, Git, GitHub, Postman, Vercel |
| **PWA** | Service Worker + Web App Manifest |
